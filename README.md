# PONDO STORE

Демонстрационный магазин Premium Streetwear. HTML5, CSS3 и Vanilla JavaScript — без сборки, сторонних библиотек и сервера заказов.

## Запуск

Для работы магазина и checkout с общей корзиной запускайте сайт через локальный HTTP-сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Остановка сервера: Ctrl+C. Используйте один адрес и порт для обеих страниц. Поведение LocalStorage для `file://` зависит от браузера; для оформления используйте HTTP.

## Файлы

- `index.html` — главная страница, доступные кнопки корзины/избранного, нативная модальная панель, уведомления и демопредупреждение.
- `style.css` — тёмная тема, адаптивные карточки, полупрозрачные подложки по категориям, боковая панель и reduced motion.
- `products.js` — 12 демонстрационных товаров. Единственный источник цен, названий и доступных размеров; структура данных сохранена.
- `script.js` — каталог, поиск, категории, новинки, меню, корзина, избранное и Hero-слайдер.
- `i18n.js` — словари UA/RU/EN, переводы товаров, привязки HTML, выбор и сохранение языка.
- `cart.js` — общая проверка корзины, ID, размеров и количеств для главной и checkout.
- `checkout.html`, `checkout.js` — отдельная демостраница с составом корзины и локальной проверкой формы.
- `images/` — локальные фото и SVG. Источники: `images/SOURCES.md`.

## Корзина и избранное

Выберите размер в карточке, затем нажмите «В корзину». Универсальные аксессуары добавляются без выбора. Одинаковые ID и размеры объединяются; разные размеры — отдельные позиции. Количество одной позиции ограничено диапазоном 1–99, удаление выполняется отдельной кнопкой.

Корзина открывается по сумке, избранное — по сердечку в шапке. Фильтры каталога не влияют на сохранённую подборку. Из избранного можно добавить товар с размером либо перейти к нему в каталоге.

Панели закрываются крестиком, Escape, кнопкой продолжения и кликом на затемнение. Фокус удерживается внутри панели и возвращается к кнопке открытия; прокрутка страницы блокируется и восстанавливается. Используется `<dialog>` — нужен современный браузер.

LocalStorage: `pondo.cart.v1` и `pondo.favorites.v1`. Формат: `{ "version": 1, "items": [...] }`. Корзина хранит только `id`, `size`, `quantity`; избранное — ID. Неизвестные ID, недоступные размеры и некорректные количества отбрасываются; дубли объединяются. Повреждённый JSON и неизвестная версия безопасно сбрасываются в памяти. Изменения синхронизируются между вкладками через событие `storage`. Если браузер запрещает сохранение, интерфейс продолжает работать в памяти и показывает предупреждение в панели.

## Фаза 4: слайдер и демооформление

Hero содержит три подборки: кроссовки, одежду и аксессуары. Автосмена — через 5 секунд; работают стрелки, клавиши ←/→ и горизонтальный свайп. Клавиатурный фокус внутри Hero, касание, открытая модальная панель и неактивная вкладка временно останавливают смену. Положение курсора не влияет на автосмену. После ручного переключения запускается новый отсчёт, когда нет условий паузы. При reduced motion автосмена и анимации отключены. CTA выбирает свою категорию и сбрасывает поисковую строку, чтобы подборка оставалась видимой.

В непустой сохранённой корзине доступна ссылка «Оформить заказ» → `checkout.html`. При недоступном LocalStorage переход скрыт, поскольку страница не сможет прочитать корзину из памяти другой страницы. Состав, размеры и количества повторно проверяются общим модулем, цены всегда берутся из `products.js`, а не из хранилища. Пустая или повреждённая корзина показывает возврат в каталог.

Форма принимает только демонстрационные контакты. Кнопка «Проверить данные (демо)» проверяет обязательные поля и показывает результат. Ничего не отправляется, личные данные не сохраняются, корзина не очищается. На checkout политика CSP запрещает отправку форм и сетевые обращения через fetch/XHR. Нет платёжных полей и настоящего заказа.

## Фаза 5: UA/RU и плавная автосмена

Основной язык — украинский (`uk`), дополнительные — русский (`ru`) и английский (`en`). На главной и checkout доступен переключатель UA | RU | EN с `aria-pressed` и областями нажатия от 44 px по высоте. На телефоне элементы шапки размещены в две строки.

`i18n.js` содержит 215 одинаковых ключей для каждого языка, включая отдельные переводы названий и цветов товаров по существующим ID. Бренды не переводятся. `PondoI18n.t(key, params)` возвращает строку и подставляет параметры; `PondoI18n.product(product, field)` возвращает перевод товара. Статические элементы используют `data-i18n`, `data-i18n-html` и привязки атрибутов (placeholder, aria-label, alt, metadata). HTML в переводах — только локальные доверенные строки.

Ключ LocalStorage для языка — `pondo.language`. При запуске без хранилища или с неизвестным значением используется `uk`; переключение остаётся доступным в памяти текущей страницы. Выбор языка обновляет `html.lang`, затем событие `languagechange` обновляет динамические карточки, панели, уведомления, Hero и checkout. Состояние фильтров, поисковая строка, размеры, текущий слайд, корзина, избранное и введённые поля checkout сохраняются. Поиск понимает названия на всех трёх языках и исходные имена моделей. Переключение синхронизируется между вкладками.

Слайдер использует один отменяемый `setTimeout` на 5000 мс. Все ветви паузы сначала очищают его; после ручного перехода или снятия паузы создаётся один новый таймер. Touch-события не устанавливают постоянную паузу. Смена вкладки и открытие модального окна также учитываются.

Переход длится 750 мс: инертный и скрытый от скринридеров снимок предыдущего Hero плавно исчезает вместе с фоном, изображением, заголовком и CTA; новое содержимое появляется согласованно. Снимок не содержит дублирующих ID и удаляется после перехода. При быстрых действиях предыдущие анимации и таймер их очистки отменяются. Высота заголовка и описания зарезервирована, чтобы слайды не сдвигали следующие блоки. При reduced motion нет автосмены и анимаций; ручная навигация остаётся доступной.

## Фаза 6: английский и линии прогресса

Добавлены естественные английские переводы всех 213 прежних ключей и двух новых — выбора EN и доступного названия слайда. Во всех трёх словарях по 215 ключей, с одинаковыми параметрами. Английский перевод покрывает главную, все слайды, товары и цвета, поиск, корзину, избранное, уведомления, ошибки, checkout и footer. Бренды и валюта ₴ сохранены. Выбор `en` сохраняется в прежнем `pondo.language`; язык по умолчанию — `uk`.

Числовой счётчик и кнопка паузы полностью удалены из Hero, включая обработчики и стили. Вместо них три равные тонкие линии на кнопках 44×44 px. Каждая имеет локализованный `aria-label` и `aria-current`, выбирает свой слайд и запускает новый отсчёт. На самых узких экранах линии размещаются над стрелками в том же блоке управления.

Один остаток времени управляет и единственным таймером автосмены, и линейной анимацией заполнения через Web Animations API. Полный цикл — 5000 мс. При клавиатурном фокусе в Hero, касании, открытой панели или неактивной вкладке остаток вычисляется по `performance.now()`, таймер и анимация останавливаются, а заполнение фиксируется. При снятии паузы цикл продолжается с оставшегося времени. Ручные стрелки, клик на линию и свайп начинают новый цикл. Crossfade остаётся 750 мс. При reduced motion активная линия показана заполненной, автосмена и анимации выключены, все ручные способы управления доступны.

## Фаза 7: компактный мобильный Hero

Пауза от наведения удалена: в коде нет состояния `hovered` и обработчиков входа/выхода курсора. Автосмена каждые 5 секунд продолжает работать при курсоре над баннером. Для доступности учитывается клавиатурный фокус (`:focus-visible`); обычный клик мышью не должен становиться постоянной паузой. Открытая панель, касание, неактивная вкладка и reduced motion обрабатываются как прежде. Таймер один, прогресс использует тот же остаток времени; ручной переход сбрасывает его на 5000 мс, crossfade остаётся 750 мс. Кнопки паузы нет.

Все новые изменения размеров ограничены `max-width: 768px`. Вертикальные отступы уменьшены примерно на 36%, заголовки и интервалы компактнее, у заголовка и описания естественная высота вместо фиксированного резерва. Длинный заголовок может переноситься, а увеличение текста увеличивает баннер. Иллюстрация помещается в адаптивную область с `aspect-ratio` и `object-fit: contain`; на типичных iPhone-ширинах 375–430 px её видимая область примерно на 20–22% меньше. Наклейка и декоративные элементы уменьшены, вертикальная подпись убрана на мобильных. Стрелки и три линии находятся в одном компактном ряду, сохраняя кнопки 44×44 px даже на 320 px. Ширина Hero учитывает safe-area inset.
